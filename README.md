## 🎯 Цель работы

Освоить три ключевых метода работы с массивами в JavaScript:

| Метод | Назначение |
|-------|-----------|
| `.map()` | Трансформация каждого элемента (N → N) |
| `.filter()` | Выборка элементов по условию (N → M, M ≤ N) |
| `.find()` | Поиск первого совпавшего элемента |

И научиться комбинировать их в **пайплайны** для решения практических задач бизнес-логики.
